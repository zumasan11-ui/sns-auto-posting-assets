広告の勝因分析

広告の勝因分析 is a creator content management service for preparing, reviewing, and publishing short-form advertising analysis videos. TikTok posts are sent only to the account authorized by the user through TikTok Login Kit, after the user has confirmed the video, caption, destination account, and posting settings.

Official website: https://zumasan11-ui.github.io/sns-auto-posting-tool/

Service Functions

Content management

Manage user-created advertising analysis text, captions, and short-form MP4 video assets before publishing.

TikTok posting

Publish approved MP4 videos to the TikTok account explicitly authorized by the user.

TikTok Integration

  • TikTok Login Kit is used to authenticate the user and connect the user's own TikTok account.
  • user.info.basic is used to display and verify the destination TikTok account before posting.
  • video.publish is used to publish a user-approved MP4 through Content Posting API Direct Post.
  • video.upload is used for the Content Posting API upload flow when a draft or upload-only flow is required.
  • The Redirect URI is under this official website domain: /tiktok/callback/.

TikTok Posting Workflow

The public workflow page shows the exact Direct Post flow used by this service: account verification, MP4 selection, caption review, privacy selection, interaction settings, final user confirmation, upload initialization, publish ID storage, and posting status checks.

View TikTok Posting Workflow

User Control

The service publishes only content that the user has created or reviewed. Before publishing, the workflow shows the connected TikTok account, selected video, caption, privacy level, comment/duet/stitch settings, and posting status. It does not post to third-party accounts, publish without user authorization, or intentionally publish content that violates TikTok policies.

Data Stored for TikTok Posting

The service stores the minimum data needed to operate the posting flow: TikTok Open ID, creator username and nickname, access token, refresh token, token expiration times, granted scopes, privacy level options, publish ID, posting status, error code, error message, and log ID. Tokens are stored securely and are used only for user-authorized TikTok posting and token refresh.
