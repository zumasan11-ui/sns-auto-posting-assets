TikTok Posting Workflow

This page demonstrates how 広告の勝因分析 uses TikTok Login Kit and Content Posting API. The user reviews the connected TikTok account, selected MP4, caption, privacy level, interaction settings, and final confirmation before a Direct Post request is made.

https://zumasan11-ui.github.io/sns-auto-posting-tool/tiktok/posting-workflow/

End-to-End Direct Post Flow

1

Connect TikTok

The user signs in with TikTok Login Kit and grants user.info.basic, video.upload, and video.publish.

2

Verify Account

The app displays the creator username and nickname so the user can confirm the destination account.

3

Review Content

The user reviews the selected MP4 video, caption, privacy level, and interaction settings before posting.

4

Publish

The app initializes Direct Post, uploads the MP4, and publishes only after the user confirms the final review screen.

5

Track Status

The app stores the publish ID and checks posting status, errors, and log IDs for troubleshooting.

6

Secure Tokens

Access and refresh tokens are stored securely and used only for authorized posting and refresh.
